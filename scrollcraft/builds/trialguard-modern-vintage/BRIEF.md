# TrialGuard Modern Vintage

Self-authored under explicit creative delegation.

## Creative authority

- Vibe: modern, vintage, interactive, tidy, playful EdTech.
- Reference: the user supplied Kidza as a broad mood reference only; no copied template structure, source, branding, or pixel-matched layout.
- Existing product: TrialGuard, a safe trial-class booking demo with PostgreSQL-backed seat confirmation.
- Assets: user-supplied, unbranded children collages only.

## Visitor journey

1. Welcome — a warm first-class invitation with a layered learning collage.
2. Understand — a four-step explanation of how a protected booking works.
3. Choose — interactive class cards carry the selected class into the booking form.
4. Trust — the reliability safeguards pair with a friendly learning collage.
5. Verify — the Reliability Lab is the visual and functional peak: the visitor can run a real last-seat race.

## Feeling curve

1. Curious — tactile paper texture, rounded lettering, and gentle depth.
2. Clear — pastel step cards reduce the process to four readable actions.
3. Confident — class choice visibly flows to the booking control.
4. Reassured — safety claims are backed by concrete database mechanisms.
5. Impressed — the Reliability Lab proves one final seat cannot be double-booked.

## Signature move

Class selection is the meaningful interaction: selecting a card preserves the choice, scrolls to the booking form, and keeps the database as the final authority.

## Layer contract

| Plane | Role | Motion |
| --- | --- | --- |
| Paper field | Cream dotted background | Static |
| Warm shape | Hero depth field | Slow decorative rotation |
| Learning collage | Focal subject | Gentle vertical drift |
| Doodles and note | Near foreground | Independent, restrained float |
| Copy and actions | Semantic foreground | Stable for readability |

## Constraints

- Keep booking, payment, roster, and reliability behavior unchanged.
- Use CSS transforms and opacity only for decorative motion.
- Honor `prefers-reduced-motion`; preserve a complete static composition.
- Art-direct mobile as a stacked composition with no horizontal overflow.
